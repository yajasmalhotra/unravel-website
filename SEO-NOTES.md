# Unravel preview — search readiness

This preview uses the supplied practice facts: low-cost virtual counselling across British Columbia, EMDR, ERP and ACT therapy, and support for depression, anxiety, OCD, PTSD, trauma and relationship concerns. The copy and artwork selection are original to Unravel, with a page flow inspired by Reyou.

## Implemented

- A title and meta description that name virtual counselling, British Columbia, key conditions and therapies.
- One H1 and descriptive section headings; readable condition and therapy copy that does not promise outcomes.
- Semantic navigation, crawlable section links, accessible controls, descriptive image alt text, and hero image priority loading.
- Canonical URL, social sharing tags, basic Organization/WebSite/WebPage structured data, robots.txt and sitemap.xml.
- A source page for every public-domain artwork used. No artwork is repeated in the page.
